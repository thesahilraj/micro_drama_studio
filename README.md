# Micro Drama Studio V5

### Cold Mode workflow

1. Put chapter `.md` files in `episodes/EPxxx/chapters/`.
2. Open/run `master prompt.md` in Anti-Gravity.
3. The orchestrator automatically creates and maintains:
   - `characters.md`
   - `names.md`
   - `production_rules.md`
   - series canon
   - episode analysis
   - ElevenLabs scripts
   - storyboard
   - NanoBanna prompts
   - audio suggestions
   - motion-comic sequence
   - QA
4. After QA passes, series memory and living master files are synchronized.

### Important
The three root master files are living files. You can edit them manually at any time; user edits have highest priority.
