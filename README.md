# Micro-Drama Studio — Cold Mode

## Goal
You only provide:
1. `/chapters/chapter 1.md` ... `/chapters/chapter 8.md`
2. `/characters.md` — canonical character definitions you control
3. `/names.md` — custom names/replacements you control

Then run `master prompt.md` in Anti-Gravity.

The orchestration layer should generate the complete production kit:
- episode analysis
- adaptation plan
- final Hinglish narration/dialogue script
- ElevenLabs-ready script
- character bible
- location/world bible
- storyboard
- shot/sequence breakdown
- NanoBanna image prompts
- character consistency/reference prompts
- image manifest
- SFX suggestions
- BGM suggestions
- manual video/motion-comic sequence plan
- QA reports
- publish package

## Human-in-the-loop
Only these are intentionally manual:
- image generation execution/re-generation
- Audacity voice/audio assembly
- SFX/BGM placement
- video editing/motion-comic assembly
- thumbnail creation
- final publishing

The system prepares the decisions and prompts so manual work becomes execution rather than planning.
